# AI LAB

AIやWebの仕組みを、小さく作って確かめるための実験サイトです。AIに実装を手伝ってもらい、手打ちなら5時間かかる作業を短くし、その分を設計と理解に使います。

## 1. ブラウザで何が起きているか

`index.html` をブラウザで開くと、ブラウザがHTMLを読み込みます。HTMLは「ページに何を置くか」を表す設計図です。`<link>` で指定した `styles.css` も読み込まれ、色や余白、スマホ対応などが適用されます。

## 2. ファイルの担当

- `index.html`: ホーム画面の文章、ボタン、ロードマップ。
- `lab.html`: Lab Notes画面。HTMLだけで別ページへ移動できる例。
- `styles.css`: サイト全体の見た目。色、余白、文字、レスポンシブ対応。
- `.gitignore`: GitHubへ送らないファイルのルール。
- `README.md`: このプロジェクトの説明書。

## 3. 文章を変更するなら

`index.html` または `lab.html` の文章を変更します。たとえばホームの大見出しは `index.html` の `<h1>`、Lab Notesの説明は `lab.html` の `<p>` です。

## 4. デザインを変更するなら

`styles.css` を変更します。色は先頭の `:root` にまとまっています。`--lime` を変えるとアクセント色を一括変更できます。

## 5. ボタンの動きを変更するなら

今のボタンはJavaScriptを使わず、HTMLのリンクです。`index.html` の `href="lab.html"` を別のページ名に変えると移動先が変わります。将来、入力やAPI接続を追加するときは `script.js` のようなJavaScriptファイルを追加します。

## 6. Codexがコードを変更すると何が起こるか

Codexがファイルを変更すると、まずこのフォルダのコードが変わります。ブラウザを更新すると、その変更を読み込んで表示が変わります。公開後は、その変更をGitHubへ送ることで、Vercelにも新しいサイトを作らせられます。

## 7. Gitとは

Gitは、ファイルの変更履歴を記録する仕組みです。「いつ、どんな変更をしたか」を戻したり比べたりできます。このプロジェクトでは、最初の状態をコミットとして記録します。

## 8. GitHubとは

GitHubは、Gitで記録したコードをインターネット上に保存・共有するサービスです。このプロジェクト専用の新しいリポジトリを作り、ここだけにコードをPushします。既存リポジトリは使いません。

## 9. Vercelとは

Vercelは、Webサイトをインターネット上で公開するサービスです。GitHubのコードからサイトを作り、URLを発行します。

## 10. GitHubからVercelへどう繋がるか

Vercelでこの新しいGitHubリポジトリを新規プロジェクトとして接続します。以後は、Codexがコードを変更 → Gitでコミット → GitHubへPush → Vercelが変更を検知してデプロイ → 公開URLの画面が更新、という流れになります。

## 現在の進み具合

Level 1のサイト作成と、Level 2のGitHub / Vercel公開は完了しています。次は外部API、AI API、APIキーの扱いへ進みます。その後、複数AI、データベース、認証、AIエージェントを必要な順に追加します。

## ローカルで見る

特別なインストールは不要です。`index.html` をブラウザで開くか、エディタのプレビューを使います。ページ遷移を試すには、ホームの「最初の実験を見る」をクリックしてください。
